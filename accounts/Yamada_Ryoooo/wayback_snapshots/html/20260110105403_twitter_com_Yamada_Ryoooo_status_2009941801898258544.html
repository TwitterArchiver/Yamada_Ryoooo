这道题目虽然背景设定得比较“抽象”，但本质上是一个逻辑严密的代数应用题。我们可以通过设立未知数来逐步拆解并求解。
1. 整理已知条件
设：
* 总人数为 20 人。
* 男生人数为 M，女生人数为 F。则 M + F = 20。
* 怀孕的女生人数为 H。
* 新冠阳性（小阳人）总人数为 P。
* 新冠阴性总人数为 N。
根据文中的描述，我们可以得出以下逻辑关系：
* 阳性 vs 怀孕： P = H + 3。
* 女生的状态： 怀孕的女生（H人）都没阳；没怀孕的女生（F - H人）全阳了。
* 所以，阳性女生人数 P_f = F - H。
* 男生的状态： “妹妹阳了几个，男的就阳了几个”。
* 所以，阳性男生人数 P_m = P_f = F - H。
* 总阳性人数 P = P_f + P_m = 2(F - H)。
* 杠数计算（最关键）：
* 测试规则：阳性（抗原或验孕）是 2条杠，阴性是 1条杠。
* 抗原测试：全班 20 人都做了。阳性 P 人，阴性 20 - P 人。
* 抗原总杠数 = 2P + (20 - P) = 20 + P。
* 验孕测试：只有女生（F人）做。怀孕 H 人，未怀孕 F - H 人。
* 验孕总杠数 = 2H + (F - H) = F + H。
* 总杠数公式： (20 + P) + (F + H) = 49。
2. 列方程组并求解
我们将上面的逻辑转化为方程组：
* * * * P + F + H = 29 （由 20 + P + F + H = 49 简化而来）
第一步：利用 (2) 和 (4) 求出 F 和 H 的关系
将 P = H + 3 代入方程 (4)：
(H + 3) + F + H = 29
2H + F = 26 \implies F = 26 - 2H
第二步：利用 (3) 求解 H
将 P = H + 3 和 F = 26 - 2H 代入方程 (3)：
H + 3 = 2[(26 - 2H) - H]
H + 3 = 2(26 - 3H)
H + 3 = 52 - 6H
7H = 49 \implies \mathbf{H = 7}
第三步：求出其他所有数值
* 怀孕人数： H = 7
* 女生人数： F = 26 - 2(7) = \mathbf{12}
* 男生人数： M = 20 - 12 = \mathbf{8}
* 阳性总数： P = 7 + 3 = \mathbf{10}
* 阴性总数： N = 20 - 10 = \mathbf{10}
3. 最终答案
验证一下：
* 女生 12 人，其中 7 人怀孕（阴），5 人没怀（阳）。
* 男生 8 人，根据“男阳=女阳”，男生有 5 人阳。
* 总阳性 = 5女 + 5男 = 10人（确实比怀孕的7人多3个）。
* 杠数：抗原（10阳10阴=30杠）+ 验孕（7怀5不怀=19杠）= 49杠。完全符合！
结论：
* 男生：8人
* 女生：12人
* 阳性：10人
* 阴性：10人
（其中有7个女生怀孕了）
